Tinkr · screens

Static design sheets for the Tinkr desktop app, drawn from design/tinkr.css. Every page opens straight from disk, at 1440×900, with no build step and no script.

The app builds these sheets: screen-1-main.html (the window), screen-2-error.html (a run that failed, as its result panel draws it), screen-4-connection.html (the connection dialog, for a local or an SSH connection), screen-5-settings.html (the preference window, with the sections the app has: General, Shortcuts, Lab and AI), screen-6-light.html and foundation.html, whose primitives the app's own stylesheet, packages/tinkr-renderer/public/tinkr.css, is a copy of. screen-3-palette.html is reference only: the app has no command palette.

Where a sheet draws what the app does not have — a command palette, the Dump, Queries and Logs panes, a stack trace, the sidebar's folder tree and its Local, SSH and Docker switch, a Saved Sessions list, the Docker connection type, and every run time, memory figure and PHP or Laravel version — it is sample data: nothing in the app collects or measures those, so the app shows no such row or figure anywhere.
